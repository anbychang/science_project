## 1. 物理基線與 GPR 目標

Phase 3 的 M1 基線為

$$
\rho_{\mathrm{phys},k,i}
=\rho_{\mathrm{MSIS,q,phase},k,i}R_k
\exp\!\left(GH_{\tau,\mathrm{phase},k,i}\right).
$$

其中 $k$ 是磁暴、$i$ 是該場的密度資料列；$H_\tau$ 是以 `SME - 65 nT` 作輸入的一階記憶濾波，單位仍為 nT，不能稱為實測加熱功率。Phase 3 已定稿的 $R_k$ 是該階段的操作倍率。Phase 4 按折重估時，另記 $c_k=\ln R_k^{(4)}$，並以 $\rho_{\mathrm{phys}}^{(4)}=\rho_{\mathrm{MSIS,q}}\exp(c_k+G^*H_{\tau^*})$ 作該折基線；不得把新估計值冒充 Phase 3 已交付的 $R_k$。密度與響應的相位聚合順序須沿用或明確重定義。

GPR 只學基線尚未解釋的對數殘差：

$$
y_{k,i}=\ln\!\left(
\frac{\rho_{\mathrm{L2},k,i}}{\rho_{\mathrm{phys},k,i}}
\right),\qquad y\sim GP(0,k(x,x')).
$$

零均值使遠離訓練特徵的修正趨近 0，密度預測因而趨近物理基線；「訓練筆數少」本身不保證每個位置都退回基線。L2 是有觀測誤差的對照資料。

給定 GPR 的對數殘差均值 $\mu_{\mathrm{gp}}$ 與標準差 $\sigma_{\mathrm{gp}}$，密度中位數與條件式 95% 預測區間為

$$
\widehat\rho_{\mathrm{median}}=\rho_{\mathrm{phys}}e^{\mu_{\mathrm{gp}}},
\qquad
\left[\rho_{\mathrm{phys}}e^{\mu_{\mathrm{gp}}-1.96\sigma_{\mathrm{gp}}},
\rho_{\mathrm{phys}}e^{\mu_{\mathrm{gp}}+1.96\sigma_{\mathrm{gp}}}\right].
$$

此區間以已擬合的物理基線及 GPR 超參數為條件，沒有涵蓋 $\tau$、$G$、$c_k$ 與超參數估計的不確定性。

## 2. Phase 4A：中心相位錨點與四維主設定

每列以 `{storm_id, time_us, u_rad}` 標識一個中心相位錨點；沿用 Phase 3 的連續相位 $u$ 與 $u\pm\pi$ 窗口，不另切固定「第幾圈」。4A 的輸入先定為 `{h_tau_phase_nt, h_24h_phase_nt, sme_phase_nt, symh_phase_nt}` 四個候選欄位。它們逐折以訓練資料標準化；欄名、取樣時刻、相位窗口內的聚合方式、缺值規則與單位須在建表前固定。

| 4A 特徵 | 要檢查的殘差規律 |
| --- | --- |
| $H_{\tau^*}$ | M1 已使用其線性對數響應；檢查較強／較弱響應時是否留下非線性殘差。每折的 $\tau^*$ 由訓練場決定。 |
| $H_{24h}$ | 檢查較長活動記憶是否影響預熱與恢復；須從連續 SME 另算，Phase 3 的 0–10 h 粗格點表不含此欄。 |
| `SME` | 檢查短期驅動變化是否提供 $H_{\tau^*}$ 之外的資訊。4A 暫按同一 $u\pm\pi$ 窗口聚合；不是錨點當分鐘的瞬時值。 |
| `SYM-H` | 檢查磁暴狀態是否提供 SME 之外的資訊；不把相關性解讀成直接加熱因果。暫按同一相位窗口聚合。 |

Phase 3 的中心相位窗口會讀到錨點之後；置中 F10.7A 亦使用未來日期。因此本計畫先定位為**離線回溯密度驗證**。若日後要求即時預測，須另定只用截止時刻以前資料的取樣與特徵，重新驗證。相位平均、濾波與差分的可用時間也須逐欄檢查。

## 3. 核函數與擬合設定

候選核函數：`ConstantKernel × RBF(ARD) + WhiteKernel`。每個標準化特徵各有一個 RBF 長度尺度 $\ell$；初值 1.0、範圍 0.01–1000。`WhiteKernel` 初值 0.1、範圍 $10^{-5}$–1；`ConstantKernel` 的初值為 1.0，其界限在實作前明定並記錄。

使用 scikit-learn `GaussianProcessRegressor`：`normalize_y=False`、`n_restarts_optimizer=5`，固定 `random_state`。零均值設定是退回物理基線的必要條件。`WhiteKernel` 表示觀測雜訊；數值穩定用的 `alpha` 需明定與記錄，不將其當成另一個待估雜訊變異。

ARD 的短 $\ell$ 表示模型對該標準化座標敏感，不能單獨證明物理因果重要性；SME、累積 SME、SYM-H 與 ap 可能相關。$\ell$ 達 1000 是特徵作用很弱的候選訊號；達 0.01 要檢查過擬合或資料問題。

## 4. Phase 4B：試跑與留一場磁暴驗證

先依 4A 設定選定一場測試磁暴，跑一折以核對來源鍵、相位窗口、特徵缺值、訓練／測試隔離、超參數與時間／記憶體成本。這是流程試跑，不拿單折結果宣稱模型有效。通過後再跑全部 25 折。

每折排除一場磁暴。其餘磁暴重新擬合 $\tau^*$、$G^*$ 與 GPR；各場 $c_k$ 只用自己的合格平靜窗口估計。測試場的 $c_k$ 若使用該場暴前 L2，成果應稱為**取得暴前觀測後的條件式回放**。測試場的磁暴窗口 L2 不參與 $\tau$、$G$、標準化或 GPR 訓練。先固定平靜窗口的截止時間及選段規則，避免把已開始的事件反應用來校準。

每一折執行：

1. 用訓練場選 $\tau^*$、$G^*$；按各場的平靜窗口估 $c_k$，再算 $\rho_{\mathrm{phys}}$ 與 $y=\ln(\rho_{\mathrm{L2}}/\rho_{\mathrm{phys}})$。GPR 訓練列只取訓練場事件窗口內 `is_valid=True` 的資料。
2. 依第 2 節建立相同欄序的訓練與測試特徵矩陣，檢查時間窗口及事件鍵沒有交叉重複。
3. `StandardScaler` 只在訓練列 `fit`，再對測試列 `transform`；逐折保存均值、標準差、欄序於 `scaler_params.json`。
4. 依第 3 節設定零均值 GPR，`fit` 訓練殘差；對留出場用 `predict(return_std=True)` 取得 $\mu_{\mathrm{gp}}$、$\sigma_{\mathrm{gp}}$。
5. 由 `kernel_` 記錄各特徵 $\ell$、訊號與雜訊變異，連同對數邊際概似及折次寫入 `gpr_hyperparams.csv`。
6. 以留出場計算對數殘差 RMSE、MAE、95% 區間涵蓋率；另看密度峰附近與全窗口，最後以磁暴等權彙總，不讓長事件單獨主導總分。

含 `WhiteKernel` 的預測標準差預定用作 L2 觀測值的條件式預測區間；實作時核對所用函式版本的 `return_std` 行為。訓練組涵蓋率只作擬合診斷，留出場涵蓋率才是主要校準檢查。另檢查遠離訓練特徵時 $\mu_{\mathrm{gp}}\to0$、$\sigma_{\mathrm{gp}}$ 增大。

## 5. Phase 4C：其他特徵候選

原提案其餘特徵先放在 4C，逐項定義並比較；不因 4A 的 ARD 長度尺度或一次留出分數就認定其物理作用。若用 25 折成績反覆挑選特徵，同一成績不能再當成未經選擇偏差的最終模型評估。

| 4C 候選 | 加入前要處理的事 |
| --- | --- |
| `F10.7` | 首個追加候選；MSIS 已使用 F10.7，須檢查背景太陽活動是否仍解釋 M1 殘差，固定來源日期。 |
| `dSYM-H / dt` | 固定差分窗與平滑規則，檢查導數雜訊。 |
| `ap_step` | 依 3 小時來源時間階梯式保持，檢查對 SME／SYM-H 之外的增量資訊。 |
| `t_onset` | 先定義可重現的 `sme_onset` 與多階段事件規則；Phase 3 的 `t0` 是 SYM-H 最低點，不可換名使用。 |
| 地方時 `sin`、`cos` | 兩欄視為一組；先定義如何代表整個 $u\pm\pi$ 窗口，不能混同軌道相位 $u$。 |

## 6. 實作前待定事項

- **資料單位**：Phase 3 已有 25 場、214,907 個有效分鐘中心相位錨點及其 $u\pm\pi$ 密度／響應；窗口高度重疊。Phase 4 可沿連續 $u$ 選代表錨點，例如在每場預先固定的 $u$ 格點上以 $\Delta u=2\pi$ 取樣，無須另切圈。既有密度相位平均可沿用；每折 $\tau^*$ 對應的響應仍須重算。格點原點、最近有效錨點的容許距離、特徵聚合與缺值規則仍待定；先計數與量測單折成本，再決定取樣間隔。原提案的「20 場約 1,800 點」不能直接套用，也不能把全部 214,907 個重疊錨點直接投入精確 GPR。
- **校準量**：決定 Phase 4 的 $c_k$ 是否重用 Phase 3 已定稿 $R_k$ 的選段規則並逐折重算；保存其來源窗口、距 onset 的時間與測試場可用資料邊界。
- **onset 與校準截止**：4A 不使用 `t_onset` 特徵，但估 $c_k$ 仍要界定不含事件反應的校準截止時間。若 4C 加入 `t_onset`，再定義可重現的 `sme_onset` 與多階段事件規則；不得用 Phase 3 的 `t0` 換名。
- **可比性**：Phase 3 的 $\tau=4.65$ h 由全部 25 場選出，現有排除測試場的曲線只重估 $G$，不是本計畫的完整留一驗證。Phase 4 須各折重估 $\tau$ 與 $G$，並分開報告純 M1 與 M1+GPR 的留出場表現。
- **成本**：每折 GPR 要做 5 次最佳化重啟；先量測單折時間與記憶體，再執行完整留一法。是否需要稀疏近似由實測決定。
