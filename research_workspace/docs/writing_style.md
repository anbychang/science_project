# 報告與圖表寫作規則

各 Phase 的報告與圖表提示使用繁體中文。完整參考：
[中文文案排版指北](https://github.com/sparanoid/chinese-copywriting-guidelines)。

## 排版

- 中文與英文、縮寫、數字、單位之間加入半形空格。
- 中文句子使用全形標點與全形括號。
- 英文專有名詞保留正確大小寫，例如 `Swarm-A`、`Orekit`、`SQLite`、`ITRF`、`GCRF`。
- 英文術語首次出現時，優先寫成「中文（English）」；程式欄位、資料表名與公式維持 code span。
- 數字使用半形字元；數字與單位之間加入空格，例如 `10 秒`、`120 秒`、`1-sigma`。
- 不重複使用問號、驚嘆號或其他標點。

## 圖表提示

- 以 `【圖 N：放置處。生成提示：...】` 標記尚未產生的圖。
- 方法示意圖不得冒充實際數據。
- 數據圖必須由 SQLite 或其他可追溯資料來源繪製，不可由影像生成模型虛構數值。
