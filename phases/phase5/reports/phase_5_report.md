# Phase 5 最終報告：整場沒有 L2 時的 GPR 判定

狀態：[done: negative]，2026-11-01。**Trial 10–12 都未改善 M1；目前不採用 GPR 修正。** 本報告只記終版。[Trial 1–13 整合報告](phase_5_trial1_13_report.md)保留嘗試過程。

## 資料條件與評分

| 項目 | 設定 |
| --- | --- |
| 目標 | 磁暴結束後修正密度；目標場整場沒有可用 L2 |
| 訓練 | 每折 20 場歷史 M1 與 L2 |
| 測試 | 每折留出 5 場完整磁暴；GPR 只讀 M1 衍生特徵，Trial 11 另讀事件時刻 |
| L2 用途 | 訓練場產生答案；測試場只在預測完成後評分 |
| 評分位置 | 三版共用 25 場、2,235 個連續三圈中心點 |

只用**對數密度 RMSE**。$\hat\rho_n$ 是受評分的密度，$\rho_{\mathrm{L2},n}$ 是 L2，$N$ 是圈數：

$$
\operatorname{RMSE}_{\log\rho}=\sqrt{\frac{1}{N}\sum_{n=1}^{N}\left[\ln\!\left(\frac{\hat\rho_n}{\rho_{\mathrm{L2},n}}\right)\right]^2}
$$

RMSE 已除以圈數，20 場與 5 場的值可用同一尺度比較；能否轉移到新磁暴，以**留出場**為準。合計值是把五折的 2,235 個留場預測一起計算，不是五個 RMSE 的平均。

五折使用固定種子 `20261030` 分組。每場測試一次，沒有按 RMSE 選場。

| 折 | 留出測試的 5 場磁暴 | 訓練圈 | 測試圈 |

$$
\operatorname{RMSE}_{\log\rho}(\text{方法})=
\begin{cases}
0.11000 & \text{Phase 4 D-model（同場擬合參考）}\\
0.20663 & \text{Phase 3 M1}\\

## Trial 10：三圈變化

### GPR 輸入與定義

令 $m_n=\ln(\rho_{\mathrm{M1},n})$；$n-1,n,n+1$ 是連續三圈。每個中心圈有三個輸入：

| 輸入欄位 | 計算式 | 告訴 GPR 什麼 |
| --- | --- | --- |
| `log_m1` | $m_n$ | 當圈 M1 密度的大小 |
| `past_log_change` | $m_n-m_{n-1}$ | 前一圈到當圈上升或下降多少 |
| `centered_log_curvature` | $m_{n+1}-2m_n+m_{n-1}$ | 升降速度是否改變；正值偏向上彎，負值偏向下彎 |

下一圈只使用 **M1**，沒有使用下一圈 L2。訓練答案是 $\ln(\rho_{\mathrm{L2},n}/\rho_{\mathrm{M1},n})$。**留場 2/5 折改善；不採用。**

## Trial 11：只學場內升降

### GPR 輸入與定義

令 $m_{k,n}=\ln(\rho_{\mathrm{M1},k,n})$，$t_{0,k}$ 是第 $k$ 場的已知事件時刻。中位數只取該場有效的中心圈：

| 輸入欄位 | 計算式 | 告訴 GPR 什麼 |
| --- | --- | --- |
| `days_from_t0` | $(t_{k,n}-t_{0,k})/1\,\mathrm{day}$ | 當圈在事件前或後，以及距離幾天 |
| `log_m1` | $m_{k,n}$ | 當圈 M1 密度的大小 |
| `relative_log_m1` | $m_{k,n}-\operatorname{median}_j(m_{k,j})$ | 當圈比該場一般密度高或低多少 |
| `centered_log_slope` | $(m_{k,n+1}-m_{k,n-1})/2$ | 前後兩圈之間的升降方向與幅度 |

訓練答案：$e_{k,n}=\ln(\rho_{\mathrm{L2},k,n}/\rho_{\mathrm{M1},k,n})$，再令 $s_{k,n}=e_{k,n}-\operatorname{mean}_j(e_{k,j})$。測試時只扣模型**預測修正值**的平均；中位數與前後圈都來自 M1，沒有使用測試場 L2。**留場 0/5 折改善；不採用。**

| 折 | 20 場訓練 M1 → GPR | 5 場測試 M1 → GPR | 同 5 場 D-model |
| --- | ---: | ---: | ---: |
| 1 | 0.20984 → 0.17546 | 0.19323 → 0.21121 | 0.10335 |
| 2 | 0.22487 → 0.19015 | 0.10705 → 0.13673 | 0.07440 |
| 3 | 0.20061 → 0.16674 | 0.22895 → 0.23573 | 0.11755 |
| 4 | 0.20585 → 0.17225 | 0.20977 → 0.21791 | 0.10849 |
| 5 | 0.19043 → 0.15842 | 0.26156 → 0.27217 | 0.13684 |

## Trial 12：整場峰值與累積量

### GPR 輸入與定義

令 $m_{k,n}=\ln(\rho_{\mathrm{M1},k,n})$；$m_k^{\max}$ 是該場有效中心圈的最大值，$t_k^{\max}$ 是**第一次**達最大值的時刻，$\tilde m_k$ 是有效中心圈的中位數。定義 $q_{k,n}=\max(m_{k,n}-\tilde m_k,0)$：

| 輸入欄位 | 計算式 | 告訴 GPR 什麼 |
| --- | --- | --- |
| `log_m1` | $m_{k,n}$ | 當圈 M1 密度的大小 |
| `log_below_peak` | $m_{k,n}-m_k^{\max}$ | 當圈低於整場 M1 峰值多少；值不大於零 |
| `days_from_peak` | $(t_{k,n}-t_k^{\max})/1\,\mathrm{day}$ | 當圈在 M1 峰值前或後，以及距離幾天 |
| `cumulative_excess` | 連續兩圈時，累加 $(q_{k,n-1}+q_{k,n})(t_{k,n}-t_{k,n-1})/(2\,\mathrm{day})$ | 高於中位數的**對數 M1 差值**按時間累積；單位是天 |

缺圈時不跨缺口累加，既有累積值保留。峰值、中位數與累積量都只由**整場 M1**計算，因此是磁暴結束後的修正。訓練答案是 $s_{k,n}=\ln(\rho_{\mathrm{L2},k,n}/\rho_{\mathrm{M1},k,n})$ 再扣該場平均；測試時只扣模型預測修正值的平均。**留場 1/5 折改善；不採用。**

| 折 | 20 場訓練 M1 → GPR | 5 場測試 M1 → GPR | 同 5 場 D-model |
| --- | ---: | ---: | ---: |
| 1 | 0.20984 → 0.17553 | 0.19323 → 0.19867 | 0.10335 |
| 2 | 0.22487 → 0.19027 | 0.10705 → 0.13019 | 0.07440 |
| 3 | 0.20061 → 0.16683 | 0.22895 → 0.24464 | 0.11755 |
| 4 | 0.20585 → 0.17233 | 0.20977 → 0.21234 | 0.10849 |
| 5 | 0.19043 → 0.15856 | 0.26156 → 0.26003 | 0.13684 |

三版在訓練場五折都降低 RMSE，留場卻未穩定改善。20 場訓練集彼此重疊，不合成另一個「25 場訓練總分」。訓練分數由原設定重新擬合；15 個留場折的分數與保存值相符，差距小於 $10^{-8}$。

## 終版決定與界線

| 資料條件 | 決定 |
| --- | --- |
| 整場沒有 L2 | 不啟用 Trial 9–12 的 GPR 修正；目前沒有可部署的無 L2 密度終版 |
| 上一圈有 L2 | Trial 9 的跨場 GPR 有條件改善；保留為[歷史結果](../../phase5-trial9/reports/trial9_pooled_orbit_gpr_report.md) |

Trial 10–12 修正的是**歷史 Phase 3 M1**，沒有試過修正 Phase 4 D-model。M1 的上游 $R_k$ 與 D-model 的每場參數都曾用同場 L2；本次只驗證 GPR **殘差層**的留場表現，沒有完成端到端無 L2 驗證。這 25 場也曾用來設計特徵，新的修正主張需用新磁暴檢驗。
