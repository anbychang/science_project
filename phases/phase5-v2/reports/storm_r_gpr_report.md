# Phase 5 V2：磁暴特徵與 GPR 歷史試驗

狀態：[historical]。本頁保留第一至十九輪探索及當時的決定。現行主線、固定三因素 Ridge、來源快照與完整限制見[Ridge 報告](storm_r_ridge_report.md)。下方各輪分數不得合併成現行模型的獨立外測結果。

## 目標值確認

狀態：[done]。要估計的 $R_k$ 是 [Phase 4 V2 共同 $\tau$ 報告](../../phase4-v2/reports/shared_tau_grid_report.md)中的 25 場事件值，來源欄位為 `phase4_v2_events.r_fit`，共同 $\tau=4.75$ h、$G=0.0006898286353844309\ \mathrm{nT}^{-1}$。已逐場以完整精度另存 `data/sqlite/phase4_v2_r_targets_v1.sqlite` 的 `phase4_v2_r_target` 表。Phase 3 原本的 $R_k$ 只是某些模型的輸入或基準；Phase 4 v1 自由 $\tau_k$ 的 $R_k$ 不是本輪目標。此目標仍是由同一批事件 L2 密度回溯擬合出的參數，並非物理真值或預報時已知量。

狀態：[historical]。25 場各做一次留出測試；兩個磁暴特徵的 GPR 尚未勝過訓練集平均值。

| 方法 | 25 場留出預測的 log-R RMSE |
| --- | ---: |
| GPR | 0.209564 |
| 每折訓練集平均 log-R | 0.207254 |

來源：Phase 4 V2 `phase4_v2_events.r_fit`，共同 $\tau=4.75$ h、$G=0.000689829\ \mathrm{nT}^{-1}$。輸入特徵是 Phase 2 `storm_minute_feature_v5` 每場完整分鐘視窗的 `max(sme_nt)`、`min(symh_nt)`；完整視窗結束後才可取得。GPR 在每折的 20 場訓練資料上標準化及擬合，預測其餘 5 場；固定亂數種子 42，五折覆蓋 25 場。

結果庫：`data/sqlite/storm_r_gpr_v1.sqlite`，`storm_r_prediction` 每場一筆，保留特徵、擬合標籤、留出預測、log 尺度標準差、該折訓練平均基準與折號。`metadata` 記錄來源、共同參數及切分設定。實測五折各 5 場，`PRAGMA integrity_check=ok`。

限制：Phase 4 V2 的共同 $\tau$、$G$ 是從同一 25 場選定，因此這是固定既有標籤的回溯性特徵試驗，不能解讀為對全新磁暴的獨立外測。GPR 有兩折的長度尺度碰到設定下界；不據此調整特徵或參數並重用這 25 場當新測試。此處 $R_{\mathrm{fit},k}$ 是密度模型的擬合參數，不是真實物理量。

決定：目前兩個特徵沒有顯示優於簡單基準的預測訊號；不要把這組 GPR 當作下游 $R_k$ 來源。

## 第六輪：Phase 3 原本 R、日期與選段距離

## 第八輪：低活動段是否真的沒有殘留響應

狀態：[done: exploratory]。第七輪只使用最大 $|H|$，無法表示響應的正負方向；此輪加入校準段內平均 $H_{4.65}$ 與其標準差，試七組候選，並對照簡單的 $R_{\mathrm{Phase3}}\exp(-G\overline H)$。這個式子只是把殘留響應換算成倍率的敏感度檢查，不是 Phase 3 校準的精確逆運算。

| 對 Phase 4 V2 `r_fit` 的比較 | 平均絕對距離 |
| --- | ---: |
| 直接使用 Phase 3 $R_k$ | 0.121346 |
| 殘留響應簡單調整 | 0.123660 |
| 第八輪 GPR 修正 | 0.138834 |

結果在 `data/sqlite/storm_r_quiet_response_trials_v8.sqlite`。25 個留出預測、35 個內層候選分數，`PRAGMA integrity_check=ok`。段內平均 $H_{4.65}$ 介於 -17.47 與 22.40 nT；以共同 $G\approx0.000690\,\mathrm{nT}^{-1}$ 換算，簡單倍率調整最多約 1.6%。這可解釋「不完全平靜」的一小部分可能偏差，無法單靠它解釋某些事件的 $R$ 差距達 0.2–0.3。

決定：用 Phase 3 的實際校準日期、距離與低活動段品質預測 $\Delta R$ 是合理的試驗定義，但目前兩輪均未改善原本 $R_k$。25 場只來自 20 個校準段；不再把同一批資料上反覆調出較低分數當成可靠進展。

## 第九輪：保留 Phase 3 R 的 GPR 先驗

狀態：[done: exploratory]。前幾輪的 GPR 對差值使用訓練平均值作遠離資料時的基準，可能把原本 $R_k$ 拉偏。這輪令差值 $\Delta R$ 的 GPR 先驗平均為 0；標準化只用訓練資料，固定平滑長度與噪聲尺度。內層從四組校準段特徵與兩個修正幅度中選擇，外層仍按共用低活動段分組 20/5。

| 對 Phase 4 V2 `r_fit` 的比較 | 平均絕對距離 | R 尺度 RMSE | log-R RMSE |
| --- | ---: | ---: | ---: |
| 直接使用 Phase 3 $R_k$ | 0.121346 | 0.150496 | 0.173268 |
| 零平均先驗 GPR 修正 | 0.120894 | 0.156456 | 0.177189 |

結果在 `data/sqlite/storm_r_prior_gpr_v9.sqlite`，有 25 個留出預測及 40 個內層分數，`PRAGMA integrity_check=ok`。25 場中有 16 場的絕對距離變小；但最大錯誤的影響使 RMSE 變大。平均絕對距離改善只有 0.000452，且這是重複看過同批事件後的探索，不構成可靠提升。

決定：若要接入 GPR，「以 Phase 3 $R_k$ 為起點，只預測小修正」比直接重猜一個 $R_k$ 更符合資料量與既有物理校準。現有 25 場尚不能證明修正有用；需要新的獨立事件及其校準段後才可判定採用。

## 第十輪：先用單因素線性模型

狀態：[working: descriptive]。目標固定為單一差值 $\Delta R=R_{\mathrm{fit}}-R_{\mathrm{Phase3}}$。每次只用一個因素和截距做普通最小平方法，外層仍是按 20 個不同低活動段分組的五折 20/5。下表相關係數先把共用同一校準段的事件平均成 20 組；正斜率折數檢查五個訓練子集的方向。MAE 是 25 場留出預測的 $R_{\mathrm{Phase3}}+\widehat{\Delta R}$ 與 Phase 4 V2 `r_fit` 的平均絕對距離。

| 單一因素 | 20 組相關係數 | 正斜率折數 | 留出 MAE |
| --- | ---: | ---: | ---: |
| 低活動段最大 $|H_{4.65}|$ | +0.463 | 5/5 | 0.120138 |
| 低活動段平均 SYM-H | -0.111 | 0/5 | 0.120794 |
| Phase 3 原本 $R_k$ | -0.097 | 0/5 | 0.123664 |
| 低活動段平均 SME | +0.344 | 5/5 | 0.126098 |
| 低活動段長度 | +0.169 | 5/5 | 0.127830 |
| 低活動段平均 $H_{4.65}$ | +0.284 | 5/5 | 0.130041 |
| 低活動段平均 ap | -0.024 | 3/5 | 0.137534 |
| 低活動段日期 | -0.210 | 1/5 | 0.140441 |
| 選段距第一個強低點的天數 | -0.088 | 3/5 | 0.152138 |

對照：完全不修正 Phase 3 $R_k$ 的 MAE 為 0.121346；每折只用訓練事件的平均差值作常數修正，MAE 為 0.125509。最大 $|H_{4.65}|$ 的線性模型低到 0.120138，R 尺度 RMSE 0.148721，與不修正的 RMSE 0.150496 差距仍很小。20 個校準段的相關係數在逐次拿掉一段後介於 +0.390 至 +0.561；低活動段最大 $|H|$ 介於 1.87 至 23.64 nT。

結果在 `data/sqlite/storm_r_linear_factors_v10.sqlite`：`linear_prediction` 225 筆、`factor_summary` 9 筆、`fold_slope` 45 筆，`PRAGMA integrity_check=ok`。所有因素都是逐一探索；九次比較與既有多輪試驗會提高偶然找到較低分數的機會。Phase 3 的選段規則已限制 `ap<=4`，因此段內平均 ap 的變動範圍很窄，不能用這裡的弱相關否定 ap 在其他時段的作用。

決定：目前最值得追查的是校準段殘留響應的**大小**，而不是日期或選段距離。它是線索，尚非已驗證的預測因素；先保留單因素關係，不升格為 GPR 的固定輸入。

## 第十一輪：留出整個校準段與置換檢查

狀態：[done: exploratory]。25 場只來自 20 個不同低活動段；逐次留出其中一段，對其餘段的事件擬合單因素直線。此處每次測試 1–3 場、訓練 22–24 場，**不是 20/5**。另把 20 段各自的平均 $\Delta R$ 隨機重排 10,000 次，檢查九個因素中最大絕對相關係數是否可能由挑選產生。置換只針對這九個因素；先前多輪探索造成的選擇偏差沒有被消除。

| 模型 | 留出整段 MAE | 留出整段 RMSE |
| --- | ---: | ---: |
| 直接使用 Phase 3 $R_k$ | 0.121346 | 0.150496 |
